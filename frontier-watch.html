What moved this month
  • Agent protocols are settling. MCP is becoming the default way to connect agents to tools and data.
  • Coding agents run for hours. Long-running agents now finish multi-step tasks without a person at every step.
  • Open-weights models closed the gap again. For many tasks, self-hosting is a real option.
Why it mattersLess about which model. More about how you connect, evaluate and govern them.
  • Integration beats model choice
  • Evals become your moat
What we tested
  • Three coding agents on the same five tasks from a real codebase: time, cost and how often a person had to step in.
  • Always-on personal agents for a week on real work: where they helped, where they made things up.
  • MCP servers for common SaaS tools: what works, and where authentication breaks.
What we foundOne agent was clearly better on refactoring, none on greenfield work.
  • Results with the setup we used
  • Repeatable on your own code
For your stack
  • Pilot one coding agent with two teams, on refactoring work. Review in six weeks.
  • Wait on always-on agents until access controls mature.
  • Write an MCP policy before teams connect their own servers.
